# Skill: Explicar Código "Con Mis Palabras" (Claro, Sencillo y Formal)

Esta skill se activa cuando el usuario necesita **explicar o entender qué hace el código fuente (`.sh` o `.c`)** de cualquiera de las unidades del TPO con sus propias palabras, o cuando comparte su interpretación de un fragmento de código para que lo validemos y pulamos.

---

## 1. Reglas de Oro de esta Skill

1. **PROHIBIDO generar archivos de documentación (`.md`) en el proyecto salvo pedido explícito:**
   - Toda la explicación se entrega **directamente en el chat** para que el usuario pueda leerla, entenderla y copiarla o adaptarla en su propio documento.
2. **Tono "Con mis palabras" pero FORMAL (Listo para copiar y pegar):**
   - **Prohibido usar lunfardo, modismos o frases informales** (no usar palabras como *"choclo"*, *"joya"*, *"che"*, *"en criollo"*, *"re bien"*).
   - El estilo debe sonar como el de un **estudiante universitario explicando el código con claridad en un trabajo práctico**: sencillo de entender, directo, sin palabras rebuscadas de manual, pero 100% presentable ante un profesor si se copia y pega textualmente.
3. **Validar la interpretación del usuario cuando comparta su idea:**
   - Si el usuario comenta qué cree que hace el código, confirmar brevemente qué partes están correctas y aclarar con precisión las dudas puntuales que haya mencionado.
4. **Explicación línea por línea + Párrafo integrador listo para usar:**
   - Desglosar qué hace cada instrucción o parámetro de forma clara y, al final, entregar un **párrafo redactado de corrido** que explique todo el código de principio a fin listo para copiar y pegar.
